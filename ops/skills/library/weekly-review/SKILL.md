# Weekly review

Reads the principal's private operating file (life areas with importance and satisfaction scores, principles, 90-day results).
This skill holds the structure only; scores and answers are written back to the private file, never to a repo.

## Steps
1. **Planned vs. done:** list last week's three result blocks and what actually happened, with sources (completed tasks, merged PRs, sent mail).
2. **Life areas:** for each area, ask for this week's satisfaction score (1–10). Show the gap to importance and whether it shrank or grew.
3. **Avoidance check:** name the tier-1 or tier-2 item that moved least and ask what is in the way. State it plainly.
4. **Next week:** propose the single most important result for the next 7 days and three result blocks that serve it.
5. **Principles:** ask which operating principle proved wrong or missing this week; draft the edit for the principal to accept.
6. **Housekeeping:** overdue items over 30 days get a decision (do / schedule / delegate / drop); confirm the next review time.

## Output
A short review note (under one page) plus proposed edits to the private operating file, shown as a diff for approval.
