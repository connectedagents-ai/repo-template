# Decision check

Reads the principal's private operating file for principles, life areas and tiers. Structure only here.

## Steps
1. Restate the decision in one sentence, with the options and the deadline. Ask for anything missing that changes the answer.
2. **Principles:** quote the operating principles that apply, and say which option each one favours.
3. **Life areas and tiers:** which areas each option helps or harms; does it touch a tier-1 item?
4. **Three-year test:** which option the principal's stated 3–5 year direction would choose.
5. **Honest answer:** the recommendation in one line, then the strongest argument against it.
6. If the decision is legal, tax, medical or fiduciary, give the analysis and name the professional whose sign-off the step legally needs.

## Rules
- Evidence over assertion: cite the principle, file or fact behind each point; mark anything unverified.
- Decide nothing irreversible on the principal's behalf; this skill recommends, the principal decides.
